### Hey, I'm Nico.

I'm a **full stack developer from Córdoba, Argentina**, working on projects at **[Soft Impulse](https://softimpulse.net)** and **[Nexobyte](https://nexobyte.com.ar)**. I build web applications, Windows tools, and SDKs that make integrations easier.

My work spans **TypeScript / Node.js** and **C# / .NET**, from the interface to the services behind it. Here you'll find peer-to-peer software, tools for the Argentine developer ecosystem, and a few experiments along the way.
